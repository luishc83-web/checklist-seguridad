# Checklist de Pentesting

## 1. Planeación y Alcance
- [ ] Definir objetivos
- [ ] Identificar activos
- [ ] Establecer reglas de compromiso

## 2. Reconocimiento
- [ ] Recolectar información pública
- [ ] Identificar dominios y subdominios
- [ ] Enumerar servicios

## 3. Escaneo y Descubrimiento
- [ ] Descubrir hosts activos
- [ ] Identificar puertos abiertos
- [ ] Detectar versiones y sistemas operativos

## 4. Análisis de Vulnerabilidades
- [ ] Buscar CVEs
- [ ] Ejecutar escáneres de vulnerabilidades
- [ ] Clasificar riesgos

## 5. Explotación
- [ ] Validar vulnerabilidades encontradas
- [ ] Obtener acceso inicial
- [ ] Documentar evidencias

## 6. Post-Explotación
- [ ] Enumerar privilegios
- [ ] Escalar privilegios
- [ ] Recolectar información relevante

## 7. Limpieza
- [ ] Eliminar artefactos temporales
- [ ] Restaurar configuraciones modificadas

## 8. Reporte
- [ ] Documentar hallazgos
- [ ] Proponer recomendaciones
- [ ] Elaborar reporte final

## 9. Automatización
- [ ] Probar GitHub Actions
